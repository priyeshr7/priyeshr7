## Selected projects

### AWS Cloud Threat Detection and Automated Incident Response

An event-driven security pipeline that uses GuardDuty findings to trigger severity-based response workflows through EventBridge and Lambda. The Python automation supports alerting, EC2 isolation, and security-event logging; the supporting AWS resources and least-privilege IAM policies are provisioned with Terraform.

`GuardDuty` `CloudTrail` `EventBridge` `Lambda` `IAM` `EC2` `SNS` `CloudWatch` `Terraform` `Python`

### [Three-Tier AWS Architecture with Terraform](https://github.com/priyeshr7/Three-Tier-AWS-VPC-Architecture-using-Terraform-)

A segmented AWS network with public, private application, and database subnets. The Terraform configuration includes an Application Load Balancer, Auto Scaling, RDS, security groups, encrypted remote state in S3, and DynamoDB state locking.

`Terraform` `VPC` `EC2` `RDS` `ALB` `Auto Scaling` `S3`

### [Containerized Application on AWS Fargate](https://github.com/priyeshr7/CloudDeploy-Containerised-Applications-with-Fargate)

A Dockerized application deployed to ECS on Fargate, with images stored in ECR and workloads isolated in private subnets. It uses an Application Load Balancer, IAM roles, CloudWatch monitoring, image scanning, and CPU-based service auto scaling.

`Docker` `ECS` `Fargate` `ECR` `VPC` `IAM` `ALB` `CloudWatch`

### [LocalRAG Bot](https://github.com/priyeshr7/LocalRAG_Bot)

A local document assistant for PDF, CSV, and text files. It uses Ollama, LangChain, and ChromaDB to keep documents, embeddings, and model calls on the user's machine while returning page- or row-level citations.

`Python` `LangChain` `Ollama` `ChromaDB` `Streamlit` `PyPDF`

### [EDA Automation Tool](https://github.com/priyeshr7/EDA-automation-Tool)

A Streamlit application for repeatable exploratory data analysis, including missing-value handling, duplicate removal, type conversion, IQR-based outlier detection, statistical analysis, and interactive visualization.

`Python` `pandas` `NumPy` `SciPy` `Seaborn` `Streamlit`

### [Text Summarization with Transformer Models](https://github.com/priyeshr7/txtsummrzn)

A comparison of extractive TextRank and abstractive BART/T5 summarization. The project evaluates output with ROUGE, exposes the selected model through a FastAPI endpoint, and packages the service with Docker.

`Python` `Hugging Face` `NLTK` `FastAPI` `Docker`
